# Running Personal OS

**Human-controlled adaptive running training.**

Running Personal OS is an early-stage running training and athlete-data platform developed by an independent developer. It brings together training plans, athlete context, connected fitness data, and structured workouts in one user-controlled workflow.

## Garmin integration

The planned Garmin integration uses the Garmin Connect Training API to deliver structured running workouts and approved training plans to Garmin Connect and compatible Garmin devices.

User control is a core design principle. Training recommendations may be created or imported from multiple sources, but a workout is not eligible for device publishing until the applicable training plan has been explicitly reviewed and approved by the athlete.

The integration is currently in development and validation. Garmin API access is not represented as approved until Garmin grants the applicable access.

## Product principles

- Athlete approval remains authoritative for training-plan and device-publishing decisions.
- Garmin data is used only to provide athlete-requested product functionality.
- Device publishing is designed to be traceable, reviewable, and fail closed when authorization is missing or stale.
- Garmin-derived data is not sold or licensed to third parties.
